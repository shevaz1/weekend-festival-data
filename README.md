# 주말어디가 축제 데이터

`주말어디가` 앱이 내려받는 공개 정적 데이터입니다. 앱 코드, 사용자 정보,
인증 정보는 포함하지 않습니다.

- `festivals.json`: 앱이 사용하는 검증된 축제 목록
- `festival-sync-report.json`: 누락·충돌 가능성이 있어 사람 확인이 필요한 항목
- 기준 원천: 한국관광공사 [대한민국 구석구석 축제](https://korean.visitkorea.or.kr/kfes/list/wntyFstvlList.do)
- 범위: 서울·경기·인천에서 현재부터 45일 안에 열리는 행사
- 갱신: 매일 1회 자동 검토 후 정상 데이터만 게시

검색 결과는 후보를 찾는 데만 사용합니다. 일정, 장소, 요금, 취소 여부는
주최 측·지방자치단체·한국관광공사 페이지처럼 공식성이 확인된 출처를 우선합니다.
원천 응답이 깨지거나 게시 가능한 행사가 6건 미만이면 마지막 정상본을 보존합니다.

현장 상황에 따라 정보가 바뀔 수 있으므로 방문 전 행사 공식 페이지를 다시
확인해야 합니다.
